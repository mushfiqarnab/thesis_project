\section*{A.4 Training Configuration}
\begin{itemize}
    \item Seeds: 42, 100, 2026, 777, and 888; 250 epochs per run; batch size 32; learning rate $10^{-4}$.
    \item Backbone: MobileNetV3-Small for all models.
    \item Hardware: RTX~4060 GPU for training; x86-64 CPU for the latency benchmark.
\end{itemize}

\section*{A.5 Orthogonality Verification}
The orthogonality error $\|W_{\text{causal}} W_{\text{conf}}^{\top}\|_F$ can be computed for any checkpoint with \texttt{model.stiefel\_decomp.verify\_mutual\_orthogonality()}. Its measured value at initialization was $1.7149 \times 10^{-6}$.
