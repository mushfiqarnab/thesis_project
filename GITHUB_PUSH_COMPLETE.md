Feature: Add CGF fairness framework with comprehensive documentation

- Implement Causal Gated Fusion (CGF) for fair multimodal threat detection
  * Dynamic modality weighting based on scar attention (focus gate)
  * Learns when to trust vision vs physiological signals

  * Counterfactual fairness: scar removal should not change predictions
  * Demographic parity: equal threat rate across scar groups
  * Equalized odds: equal TPR and FPR across sensitive attribute
