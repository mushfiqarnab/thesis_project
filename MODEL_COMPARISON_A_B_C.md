# MODEL COMPARISON - THREE ARCHITECTURES (A, B, C)

## 📊 CONTEXT: What Results Are Those?

The results I showed you earlier (53.15%, 41.52%, etc.) are **model evaluation metrics** on the **validation set (2,000 samples)** from your multimodal threat detection dataset.

### What Each Metric Means
- **Accuracy:** Overall correctness (% correct predictions)
- **Precision:** False alarm rate (% of threat predictions that are correct)
- **Recall:** Detection rate (% of actual threats caught)
- **F1 Score:** Balance between precision and recall
- **AUC-ROC:** Ranking ability (0.5=random, 1.0=perfect)

These were generated by running:
```bash
python run_comprehensive_analysis.py --checkpoint [model_path]
```

## 🎯 ARCHITECTURE DIFFERENCES EXPLAINED

### Model A: Simple Baseline
```
Vision Input (Image)     Physiology Input (HRV, GSR)
      ↓                              ↓
Vision Features          Physiology Features
(224×224 → MobileNet)    (2 values)
      ↓                              ↓
   [Features]   ←→   Simple Concat   ←→   [Features]
                           ↓
                    Classification Head
                           ↓
                      Safe/Threat
```
**Fusion:** Direct concatenation (no interaction learning)

---

### Model B: Counterfactual Concat
```
Vision Input (Image)     Physiology Input (HRV, GSR)
      ↓                              ↓
Vision Features          Physiology Features
      ↓                              ↓
   Counterfactual    ←→   Counterfactual   ←→
   Modification           Modification
      ↓                              ↓
   [Features]   ←→   Concat + Aware   ←→   [Features]
                           ↓
                    Classification Head
                           ↓
                      Safe/Threat
```
**Fusion:** Concatenation with counterfactual guidance (considers fairness)

---

### Model C: Counterfactual Guided Fusion (CGF)
```
Vision Input (Image)     Physiology Input (HRV, GSR)
      ↓                              ↓
Vision Features          Physiology Features
      ↓                              ↓
   Counterfactual    ←→   Counterfactual   ←→
   Aware Features        Aware Features
      ↓                              ↓
     Attention         Attention
    Weights           Weights
      ↓                    ↓
   [Features]   ←→   Guided Fusion   ←→   [Features]
                   (learns importance)
                           ↓
                    Classification Head
                           ↓
                      Safe/Threat
```
**Fusion:** Attention-weighted fusion with counterfactual guidance (learns feature importance + fairness)
